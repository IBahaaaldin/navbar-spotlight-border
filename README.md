## ✨ Features & Micro-Interactions

- **Clean Minimal Canvas**: Pitch black (`#000000`) or crisp white (`#ffffff`) canvas with zero distractions.
- **Dead-Center Ergonomics**: Positioned dead-center both horizontally and vertically across desktop and mobile screens.
- **Cursor Spotlight Tracking**: Real-time cursor coordinates (`--mouse-x`, `--mouse-y`) cast a dynamic radial glow that illuminates the border wherever you move.
- **Iridescent Chromatic Sheen**: Multi-stop gradient border with subtle cyan-to-violet reflections.
- **Animated Shimmer Badge**: Sweeping gradient sheen animation highlighting live project availability.
- **Zero Text Wrapping**: Strict `whitespace-nowrap` guarantees titles, names, and buttons stay on a single row.
- **Instant Theme Switcher**: Built-in toggle seamlessly transitions between Dark and Light mode.
- **Responsive Mobile Drawer**: Native slide-down menu with numbered links, live location status, and contact button.
- **Self-Contained**: 100% pure HTML5 + Tailwind CSS CDN + inline SVGs with zero build requirements.

## 🚀 Quick Start

### 1. View Locally
Simply clone and open `index.html` in your browser:
```bash
git clone https://github.com/IBahaaaldin/navbar-spotlight-border.git
cd navbar-spotlight-border
open index.html
```

### 2. Re-record Assets
To re-record desktop & mobile screenshots and videos:
```bash
node record.js
```
